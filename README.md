# Good Interior Design Studio - Luxury Architecture & Interiors

A full-stack web application for Good Interior Design Studio featuring a high-end dynamic user interface and a comprehensive Executive Admin Dashboard.

## Architecture

- **Frontend**: React (Vite), Custom Luxury CSS, React Icons, Context API
- **Backend**: Node.js, Express.js, MongoDB Atlas (Mongoose), Nodemailer (Gmail SMTP)

## Project Structure

```text
Interior Design Website/
├── frontend/             # Client-facing React Application & Admin Suite
├── backend/              # Node.js Express REST API & Database Models
└── README.md
```

## Features

- **Dynamic Page Content Management**: Fully dynamic Home, About Us, Services, Portfolio Projects, Galleries Showcase, Contact, Blog, Client Testimonials, and Auth Branding.
- **Client Booking & Consultations**: Real-time consultation requests and contact form submissions.
- **Gmail SMTP Integration**: Send dynamic, personalized email replies to clients directly from the Admin Dashboard.
- **Admin Control Suite**: Real-time management of dynamic site settings, categories, and authentication pages.

## Getting Started

### 1. Backend Setup
```bash
cd backend
npm install
# Create a .env file based on .env.example
npm start
```

### 2. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
